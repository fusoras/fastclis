- Usa pnpm, no npm
- Al escribir CSS, prioriza utilizar nesting CSS para las clases que dependan de su padre
- No levantes servidores ni hagas builds, simplemente avisa, que lo hara el usuario.
- Ejecuta `node --run format` despues de agregar o modificar cualquier archivo de código (JS, CSS, HTML, Astro, etc.) para formatearlo.
- Usa los estilos de `@/src/styles/dsystem.css` solo modificable los CUSTOM PROPERTIES. Para nuevos estilos globales de este proyecto usa `@/src/styles/global.css`
